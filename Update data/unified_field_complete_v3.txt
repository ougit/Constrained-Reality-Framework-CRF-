I. FIELD & GENERATION LAYER (กลุ่มสนามและแรงเสียดทานแห่งอัตถิภาวะ)
═══════════════════════════════════════════════════════════════════════════════════

นิยามตัวแปรพื้นฐาน:
    • F_b(t) (Existential Friction): แรงเสียดทานแห่งอัตถิภาวะ
      แรงต้านที่เกิดจากการที่การรับรู้ (Consciousness) ปะทะกับข้อจำกัดทางกายภาพ
      และสภาวะแวดล้อม

    • d (Ontological Dissonance): ระยะห่างความขัดแย้งระหว่าง "สิ่งที่ปรากฏอยู่"
      กับ "สิ่งที่โครงสร้างตัวตนยึดถือ" (ยิ่งห่าง สัมประสิทธิ์ μ(d) ยิ่งสูง)

    • Ω(x) (Cognitive-Affective Landscape): ภูมิทัศน์ของการรับรู้
      พื้นที่เชิงสภาวะที่จิตกำลังเผชิญอยู่

เงื่อนไขพื้นฐาน:
    F_b(t) > 0 ใน Embodied domain (ตราบที่มีร่างกาย ย่อมมีแรงเสียดทานเสมอ)

    หาก F_b = 0 ⇒ ΔP_total = 0 (จะไม่มีพลวัตการขยายตัวเกิดขึ้นในระบบที่มีเวลา)

II. POTENTIAL STRUCTURE (โครงสร้างศักยภาพและทิศทาง)
═══════════════════════════════════════════════════════════════════════════════════

นิยามตัวแปร:
    • P_c(t) (Self-Actualizing Vector): เวกเตอร์แห่งการตระหนักรู้แจ้ง
      แรงผลักที่เกิดจากความโปร่งใส (Lucidity) ที่มุ่งสู่วิวัฒนาการของตนเอง
      (Push component) — วัดได้เป็น B(t) = P_c(t)/P_max ∈ [0,1] (Buoyancy measure)

    • P_k(t) (Entropic Turbidity / Karmic Gravity): แรงโน้มถ่วงแห่งความขุ่นมัว
      แรงดึงรั้งจากความเคยชิน (Conditioning) และกลไกป้องกันตัวที่ดึงระบบ
      กลับสู่จุดคุ้นเคย (Pull component)
      หมายเหตุ: P_k (มวลความขุ่นรวม) ลดลงช้ามาก แต่สิ่งที่ระบบ "รู้สึก" จริงๆ
      คือ P_k^{effective} ซึ่งผันแปรได้มากกว่า — ดู Section III.2

    • D(t) (Net Directionality): ทิศทางสุทธิของการขับเคลื่อนระบบ

    • P_max: ขีดสูงสุดของ Lucidity capacity ในระบบนั้น

สมการพื้นฐาน:
    D(t) = P_c(t) - P_k(t)

เงื่อนไขทิศทาง:
    D(t) > 0: ระบบขยายตัวสู่ศักยภาพสูงกว่า
    D(t) = 0: สมดุลแบบเมตาสเตเบิล (Metastable Equilibrium)
    D(t) < 0: ระบบถดถอยสู่ความขุ่นมัว

III. TURBIDITY DYNAMICS (พลวัตแห่งความขุ่นมัวและเกณฑ์วิกฤต)
═══════════════════════════════════════════════════════════════════════════════════

III.1 ขีดจำกัดล่างและมวลความขุ่นที่สัมผัสได้จริง

เงื่อนไขขีดจำกัดล่าง (Somatic Floor):
    P_k(t) ≥ ε_residual > 0

    โดย ε_residual ≈ 10–50 (หน่วยเชิงสัมพัทธ์)

    • ε_residual (Somatic Baseline): ขีดจำกัดล่างระดับเซลล์และระบบประสาท
      ตราบใดที่ระบบกายภาพยังต้องรักษาสมดุล (Homeostasis) ย่อมมี noise พื้นฐานเสมอ
      ซึ่งไม่สามารถลบให้เป็นศูนย์ได้ใน Embodied system

มวลความขุ่นที่สัมผัสได้จริง (Effective Turbidity):
    P_k^{effective}(t) = P_k(t) · (1 - B(t)) · (1 + α · F_b(t))

    โดยที่:
        • B(t) = P_c(t)/P_max: ดัชนีการลอยตัว (Buoyancy measure)
        • α: สัมประสิทธิ์การขยายของแรงเสียดทานต่อความรู้สึกหนัก

    ความหมายเชิงระบบ:
        P_k (มวลรวม) และ P_k^{effective} (น้ำหนักที่รู้สึก) เป็นคนละสิ่งกัน
        P_k ลดลงช้ามาก — เหมือนของจริงในห้องที่ยังไม่ลดลง
        P_k^{effective} ผันแปรตาม P_c และ F_b ได้อย่างมหาศาล
        เหมือนห้องที่จัดแล้ว — ของยังเท่าเดิม แต่ไม่รู้สึกทับถมอีกต่อไป

สมการการเปลี่ยนแปลงของความขุ่นมัว:
    dP_k/dt = -δ_refine · P_c + η · F_b(t)

    โดยที่:
        • δ_refine: อัตราการขัดเกลา (Refinement Rate)
        • η: สัมประสิทธิ์การแปลงแรงเสียดทานเป็นความขุ่นมัว

III.2 เกณฑ์วิกฤตสองด่าน (Two Critical Thresholds)

ระบบไม่เปลี่ยนแปลงแบบต่อเนื่อง แต่มีด่านวิกฤตสองจุดที่ต้องผ่าน:

ด่านที่ 1 — เกณฑ์การตื่นรู้ (Awareness Threshold):
    P_k^{effective}(t) ≥ P_awareness  →  Θ_awareness = 1

    ความหมาย: มวลความขุ่นมัวที่สัมผัสได้หนักพอให้ระบบ "รู้" ว่ามีแรงต้านอยู่
    นี่คือจุดที่เปลี่ยนจาก "ก็อย่างนี้แหละ" เป็น "มีอะไรบางอย่างผิดปกติ"
    รู้แล้ว แต่ยังเปลี่ยนไม่ได้

ด่านที่ 2 — เกณฑ์การทะลุผ่าน (Breakthrough Threshold):
    P_total(t) = P_k^{effective}(t) + P_c^{potential}(t) ≥ P_breakthrough  →  Θ_breakthrough = 1

    โดยที่ P_c^{potential}: กำลังโปร่งใสที่สะสมพร้อมใช้งาน (latent lucidity)

    ความหมาย: กำลังรวมมากพอที่จะเริ่มกระบวนการจัดเรียงโครงสร้างใหม่ (Reorder)
    ไม่ใช่แค่รู้ว่าต้องเปลี่ยน แต่มี "ที่ยืน" ให้เริ่มเปลี่ยนได้

───────────────────────────────────────────────────────────────────────────────────
III.3 สามเส้นทางแห่งพลวัต (Three Dynamic Paths)

เมื่อ Θ_awareness = 1 แล้ว ระบบจะเดินไปตามหนึ่งในสามเส้นทาง:

    Path A (Retreat — ถอยกลับ):
        Θ_awareness = 1, Θ_breakthrough = 0, dF_b/dt < 0
        ระบบเลือกลดแรงเสียดทาน → กลับสู่สภาวะชิน
        แต่ตอนนี้รู้ว่าชิน ความทุกข์จึงเพิ่มขึ้นเพราะมีสติกับมันมากขึ้น

    Path B (Stagnation — ติดหล่ม):
        Θ_awareness = 1, Θ_breakthrough = 0, dF_b/dt ≥ 0
        รู้แต่ P_total < P_breakthrough — ทรมานที่สุด
        เพราะเห็นชัดว่าต้องเปลี่ยน แต่ไม่มี "ที่ตั้ง" ให้เริ่มเปลี่ยน
        ไม่ใช่ความอ่อนแอ แต่เป็นข้อจำกัดของพลังงาน

    Path C (Breakthrough — ทะลุผ่าน):
        Θ_awareness = 1, Θ_breakthrough = 1
        กำลังรวมถึงจุด → P_c เริ่มทำงานในโหมด Reorder
        ความทุกข์ไม่หาย แต่ระบบเริ่มจัดการกับมันได้

IV. EXPANSION MODE (Capacity Stress-Yielding)
═══════════════════════════════════════════════════════════════════════════════════

โหมดการขยายความจุผ่านความเค้น (ต้องการแรงเสียดทานภายนอก)

สมการ:
    ΔCapacity = ∫_{t_0}^{t_1} [F_b(t) - F_crit] · H(F_b - F_crit) dt

    โดยที่:
        • F_crit: แรงเสียดทานวิกฤติที่จำเป็นต้อง overcome
        • H(x): ฟังก์ชัน Heaviside step (H(x) = 1 ถ้า x > 0, 0 ถ้า x ≤ 0)

หลักการ:
    การจะเพิ่มขีดความสามารถ (Capacity) ระบบจำเป็นต้องเผชิญหน้ากับแรงเสียดทาน
    ที่สูงกว่าจุดวิกฤต (F_crit) เสมือนกล้ามเนื้อที่ฉีกขาดเพื่อสร้างใหม่
    สิ่งนี้เกิดขึ้นได้จริงก็ต่อเมื่อ Θ_breakthrough = 1 แล้วเท่านั้น —
    มิเช่นนั้นแรงเสียดทานที่สูงจะเป็นเพียง F_b ที่เพิ่ม P_k^{effective}
    โดยไม่เกิด Capacity ใหม่

V. INTEGRATION MODE (Metabolic Refinement)
═══════════════════════════════════════════════════════════════════════════════════

โหมดกระบวนการเผาผลาญและตกผลึกประสบการณ์ (ขับเคลื่อนจากภายใน)

สมการหลัก (ฉบับที่รวม threshold):
    dP_c/dt = Θ_breakthrough · [δ_reorder · P_k^{effective} - κ · (P_c - P_c^{eq})]

    โดยที่:
        • Θ_breakthrough: ฟังก์ชัน Heaviside ที่ปลดล็อก P_c (= 0 ก่อนทะลุ, = 1 หลังทะลุ)
        • δ_reorder: อัตราการจัดเรียงใหม่ (Reorder Rate) ซึ่งทำงานบน P_k^{effective}
        • P_c^{eq}: ระดับ P_c สมดุลที่เป็นเป้าหมายของการจัดเรียง
        • κ: สัมประสิทธิ์การปรับเข้าสู่สมดุล

    ความหมาย: P_c ไม่เกิดขึ้นอัตโนมัติจากการที่ P_k สูง
    แต่ต้องผ่านเกณฑ์ทั้งสองก่อน — awareness ก่อน breakthrough ถึงจะมี Reorder

รูปแบบฟังก์ชันของอัตราการขัดเกลาและจัดเรียง (Asymptotic Resistance):
    δ_refine = k · (P_k - ε_residual)^{-α}        // ทำงานบน P_k รวม
    δ_reorder = k · (P_k^{effective} - ε_residual)^{-α} · Θ_breakthrough  // ทำงานบน effective

    โดยที่:
        • k: ค่าคงที่สัดส่วนที่ขึ้นกับสภาพแวดล้อมของระบบ
        • α: ค่าอำนาจของอสมปทาน (โดยทั่วไป α ≥ 2)
        • เงื่อนไข: เมื่อ P_k^{effective} → ε_residual⁺ แล้ว δ_reorder → ∞

ความหมายเชิงระบบ:
    แรงขับไม่ใช่ความเจ็บปวด แต่คือ δ_reorder (การจัดเรียงใหม่) ที่ทำหน้าที่เปลี่ยน
    มวลความขุ่นมัวที่สัมผัสได้ (P_k^{effective}) ให้กลายเป็นความโปร่งใส (P_c)
    ยิ่ง P_k^{effective} เข้าใกล้ ε_residual มากเท่าไหร่
    การจัดเรียงก็ยิ่งต้องอาศัยพลังงานสูงขึ้นเป็นทวีคูณ (Asymptotic Resistance)

VI. ENERGY REGULATION & LAG (การควบคุมพลังงานและความหน่วง)
═══════════════════════════════════════════════════════════════════════════════════

สมการพลังงานรวม:
    E_total(t) = E_kinetic(t) + E_potential(t) + E_dissipated(t)

    โดยที่:
        • E_kinetic: พลังงานจลน์ของการดำเนินการ (Action)
        • E_potential: พลังงานศักย์ที่เก็บสะสมในรูปแบบ P_c
        • E_dissipated: พลังงานที่สูญเสียไปกับความขุ่นมัวและแรงเสียดทาน

ความหน่วงของระบบ (System Lag):
    τ_lag = ∂E_potential/∂t · (∇Ω)^{-1}

    ความหน่วงแสดงถึงเวลาที่ระบบต้องใช้ในการปรับตัวต่อการเปลี่ยนแปลงของภูมิทัศน์จิต
    และเป็นเหตุผลที่ Path C (Breakthrough) ไม่นำไปสู่การเปลี่ยนแปลงทันที
    แต่ต้องผ่านช่วง lag ที่ระบบกำลัง reorder อยู่เบื้องหลัง

VII. ESCAPE & PRESENCE INTENSITY (การหลุดพ้นและความหนาแน่นของการดำรงอยู่)
═══════════════════════════════════════════════════════════════════════════════════

เงื่อนไขการหลุดพ้น (Escape Condition):
    ∫_0^T D(t) dt > Θ_escape

    โดยที่ Θ_escape คือเกณฑ์ขั้นต่ำของการสะสมทิศทางที่จำเป็นเพื่อหลุดพ้นวังวน

ความหนาแน่นของการดำรงอยู่ (Presence Intensity) — ฉบับ Regularized:
    I_presence = |P_c|² / (F_b + ε_residual + κ·R)

    โดยที่:
        • R (Intrinsic Curvature): ความโค้งมนของสนาม Φ เอง
        • κ: ค่าคงที่ coupling ระหว่าง P_c กับ geometry ของ Φ

ใน Timeless Field (F_b = 0):
    I_presence = |P_c|² / (ε_residual + κ·R)  →  finite เสมอ

    ความหมาย: แม้ไม่มีแรงเสียดทานภายนอก สนามยังมี "แรงตึงตัวภายใน"
    จากความโค้งมนของตัวเอง — นี่คือสิ่งที่ทำให้ Φ "มีตัวตน" โดยไม่ต้องมีอะไรมากดดัน

VIII. SURPLUS ALLOCATION (การกระจายทรัพยากรส่วนเกินแบบปรับตัว)
═══════════════════════════════════════════════════════════════════════════════════

เมื่อข้ามพ้นเพดานของการยึดติด (Θ_breakthrough = 1 อย่างยั่งยืน)
พลังงานที่เหลือ (Surplus) จะถูกจัดสรรอย่างเป็นพลวต:

สมการการจัดสรร:
    S = L_inner + E + I + C_b

    โดยที่:
        • S: พลังงานส่วนเกินทั้งหมด (Surplus)
        • L_inner: พลังงานที่หล่อเลี้ยงความกระจ่างชัด (Lucidity)
        • E: พลังชีวิตพื้นฐานเพื่อการทำงานและเยียวยาของระบบกายภาพ (Vital Energy)
        • I: การแผ่ขยายของ P_c สู่โลกภายนอก (Presence Intensity / Action)
        • C_b: ต้นทุนขอบเขต (Boundary Cost)

เงื่อนไขการปรับตัวแบบไดนามิก:
    ∂L_inner/∂t = η · S · (1 - e^{-λ·D(t)})
    ∂E/∂t = γ · S · e^{-λ·D(t)}
    ∂I/∂t = ζ · S · (D(t)/D_max)

    โดยที่:
        • D_max: ค่าสูงสุดของทิศทางที่เป็นไปได้
        • η, γ, ζ: ค่าสัมประสิทธิ์การจัดสรร (η + γ + ζ = 1 - κ_b, โดย κ_b สำหรับ C_b)
        • λ: อัตราการลดตัวของการจัดสรรตามทิศทาง

ความหมายเชิงกลไก:
    เมื่อทิศทางชัดเจน (D(t) สูง) พลังงานส่วนเกินจะไหลไปสู่ L_inner และ I มากขึ้น
    เมื่อทิศทางไม่ชัดเจน พลังงานจะถูกสำรองไว้ใน E เพื่อรักษาสมดุลพื้นฐาน

IX. CEILING CONSTRAINT (ข้อจำกัดและ Phase Transition)
═══════════════════════════════════════════════════════════════════════════════════

ฟังก์ชันต้นทุนขอบเขตแบบ Phase-Aware:

    C_b(d) = {
        C_0 · tanh(β · (d - d_crit))       ถ้า d < d_max
        C_0 · [1 - σ · (d - d_max)]        ถ้า d_max ≤ d < d_break
        0                                  ถ้า d ≥ d_break
    }

    โดยที่:
        • d: ระยะห่างความขัดแย้งเชิงภววิทยา (Ontological Dissonance)
        • d_crit: จุดวิกฤติที่ต้นทุนเริ่มเพิ่มขึ้นอย่างมีนัยสำคัญ
        • d_max: ขอบเขตสูงสุดที่ระบบยังคงเสถียร
        • d_break: จุดที่ขอบเขตแตกสลาย (เข้าสู่ Timeless Field)
        • C_0: ต้นทุนพื้นฐาน
        • β: ความชันของการเพิ่มต้นทุน
        • σ: อัตราการลดต้นทุนเมื่อเข้าใกล้การเปลี่ยนผ่าน

ลักษณะเฟส:
    Phase 1 (d < d_crit): ต้นทุนต่ำ ระบบยืดหยุ่น
    Phase 2 (d_crit ≤ d < d_max): ต้นทุนเพิ่มสูง ระบบตึงตัว
    Phase 3 (d_max ≤ d < d_break): ต้นทุนลดลง ระบบเริ่มหลุดพ้น
    Phase 4 (d ≥ d_break): ไร้ต้นทุน เข้าสู่สภาวะไร้เวลา

ความหมาย:
    เมื่อระบบเข้าใกล้ขอบเขตของ Ontological Dissonance ตัว C_b จะเพิ่มขึ้น
    แต่หากหลุดออกนอกขอบเขต C_b จะลดทอนพลังงานลง ป้องกันการแตกสลายของระบบ

II.5.A โครงสร้างของตัวตน (The Structure of Self)

ตามสมการใน II ตัวตนไม่ใช่ภาชนะที่กักเก็บประสบการณ์
แต่เป็นกระบวนการที่ประกอบจากสองส่วนที่แยกไม่ออก:

    Self(t) = P_c(t) + Φ(t)

    โดยที่:
        • P_c(t): ส่วนรับรู้ — สิ่งที่ระบบ "รู้สึก" และ "เห็น" ในปัจจุบัน
        • Φ(t): กำลังสะสม — ผลรวมของการขัดเกลาทั้งหมดที่ผ่านมา

    P_c และ Φ ไม่ใช่สองสิ่งแยกกัน แต่เป็นสองมิติของกระบวนการเดียว
    เหมือนในลูกโป่งที่มีทั้งน้ำขุ่น (P_k) และไอน้ำ (P_c ที่ผ่านการขัดเกลา)

ภาพเปรียบเทียบ — ลูกโป่งแห่งกำลังรวม:

    P_total คือลูกโป่งทั้งใบ
    P_k     คือน้ำขุ่นที่อยู่ในลูกโป่ง
    P_c     คือไอน้ำที่ระเหยขึ้นภายในลูกโป่ง

    กระบวนการ Integration (δ_reorder) คือการเปลี่ยนน้ำขุ่นเป็นไอน้ำ
    ไอน้ำไม่ออกไปข้างนอก — มันยังอยู่ในลูกโป่ง เป็นส่วนหนึ่งของ P_total

    เมื่อไอน้ำเพิ่ม ลูกโป่งขยาย
    กำลังรวม (P_total) เติบโต ไม่ใช่เพราะสิ่งเก่าหายไป
    แต่เพราะสิ่งเก่าเปลี่ยนสถานะ

    สมการ:
        ΔP_total = Δ(P_k → P_c) + Δ(F_b → P_k) - E_dissipated

    น้ำขุ่นที่กลายเป็นไอยังอยู่ในกำลังรวม — เพียงแต่ไม่ทับถมอีกต่อไป

ความหมายเชิงตัวตน:
    "ตัวตน" ไม่ใช่สิ่งที่หายไปเมื่อ P_k ลดลง
    แต่ตัวตนเปลี่ยนสถานะ — จากน้ำขุ่นที่ตกตะกอน เป็นไอที่ขยายพื้นที่

───────────────────────────────────────────────────────────────────────────────────
II.5.B ความต่อเนื่องของกำลังรวมข้ามรอบ (Cross-Cycle Continuity)

เมื่อ P_total ถูกนิยามว่าเป็นลูกโป่งที่สะสม คำถามตามมาคือ:
เกิดอะไรขึ้นกับลูกโป่งเมื่อรอบหนึ่งสิ้นสุดและรอบใหม่เริ่มต้น?

สิ่งที่ทราบ:
    P_total ไม่ลดลงข้ามรอบ — ปริมาณกำลังรวมคงอยู่

    แต่ P_k ในรอบใหม่มีน้ำหนักเบากว่ารอบก่อน
    เหมือนมวลเท่าเดิมแต่แรงโน้มถ่วงลดลง

    นิยาม:
        P_k^{(n+1)}(t=0) = P_k^{(n)}(t=∞) · w_cycle

        โดยที่ w_cycle < 1 คือตัวแปรการลดน้ำหนักข้ามรอบ

    ค่า w_cycle และกลไกที่ทำให้ P_k เบาลงยังเป็น unknown
    สมการนี้จึงระบุได้เพียงทิศทาง ไม่ใช่ค่าจริง:

        w_cycle = ?  [unknown — กระบวนการระหว่างรอบยังไม่ทราบ]

สิ่งที่ยังไม่ทราบ — ช่วงระหว่างรอบ (Inter-Cycle Gap):
    ∃ process(n→n+1) : P_k^{heavy} → P_k^{lighter}

    กลไกของ process นี้อยู่นอกขอบเขตของสมการปัจจุบัน
    ระบุได้แค่ว่ามันเกิดขึ้น และผลของมันคือ w_cycle < 1
    ไม่สมควรใส่กลไกที่ยังไม่รู้ลงในสมการ

ค่ามาตรฐานในระดับมนุษย์ (Human Baseline):
    ในระดับมนุษย์ควรมีค่า P_k^{standard} ที่เป็นเกณฑ์เริ่มต้นของรอบ

        P_k^{(n+1)}(t=0) ≥ P_k^{standard}

    P_k^{standard} คือขีดต่ำสุดที่ทำให้ระบบสามารถเริ่มรอบในรูปแบบมนุษย์ได้
    ถ้า P_k ต่ำกว่านี้ รอบใหม่จะไม่เริ่มในรูปแบบมนุษย์

    ความหมาย:
        กำลังขุ่นที่มากเกินไป (P_k สูงมาก) ทำให้จมลึก
        รอบใหม่อาจเริ่มในรูปแบบที่ต่ำกว่ามนุษย์
        กำลังขุ่นที่เบาพอ (P_k ≥ P_k^{standard}) รอบใหม่จึงเริ่มในระดับมนุษย์ได้

สภาวะของกำลังรวมในรอบแรกๆ:
    รอบที่ 1–2 (รอบต้น):
        P_total ≈ P_k  (กำลังขุ่นแทบล้วน, P_c ≈ 0)

        แรงเสียดทานและแรงดันภายในเป็นแรงขับเกือบทั้งหมด
        ยังไม่มีกลไก δ_reorder ที่ทำงานได้จริง
        ระบบวนซ้ำตามแรงดันภายใน — น้ำขุ่นที่หมุนวนโดยไม่ระเหย

เงื่อนไขการรับรู้:
    P_c(t) รับรู้ Φ ได้ก็ต่อเมื่อ P_total(t) ≥ P_awareness
    ถ้าไม่ถึงเกณฑ์ — ไม่รับรู้ ตามสมการปกติ ไม่มีกลไกพิเศษ

    สิ่งที่ถ่ายทอดข้ามรอบจึงปรากฏเป็น:
        • รูปแบบการตอบสนอง (response patterns)
        • ความโน้มเอียงของระบบ (system tendencies)
        • ระดับ P_awareness เริ่มต้น ที่อาจสูงกว่ารอบก่อน
    ไม่ใช่ความทรงจำละเอียด แต่เป็น signature ที่ฝังอยู่ใน Φ

───────────────────────────────────────────────────────────────────────────────────
II.5.C โครงสร้างสภาวะและขีดจำกัดของการเคลื่อนผ่าน
        (State Architecture & Transition Limits)

สภาวะในระบบนี้ไม่ใช่จุดบนเส้นตรง แต่เป็นชั้นที่มีเกณฑ์ผ่านของตัวเอง

โครงสร้างสภาวะ:

    สภาวะ 1–4   : Embodied Struggle
                   P_k^{eff} ครองระบบ, D(t) ผันผวน
                   การทะลุในชั้นนี้คือชั้นย่อย — เดินหน้าได้หน่อยแล้วหยุด
                   ไม่ได้หมายความว่าข้ามไปสภาวะ 5

    สภาวะ 5–6   : Transition Zone (กลางทาง)
                   P_c สะสมพอให้ส่วนรับรู้เห็นรูปแบบและเส้นทาง
                   การขยายจาก 5→6→7→8 เกิดได้ต่อเนื่อง
                   เพราะ P_total มากพอให้ Θ_breakthrough ทำงานซ้ำๆ ได้

    สภาวะ 7–8   : Sustained Expansion
                   δ_reorder ทำงานได้อย่างมีเสถียรภาพ
                   ทิศทาง D(t) > 0 คงที่มากขึ้น
                   ก้าวอาจใหญ่หรือเล็กแล้วแต่ตัวแปร

    สภาวะ 9     : Last Binding (จุดยึดโยงสุดท้าย)
                   F_b จากภายนอกแทบไม่ส่งผลโดยตรงอีกต่อไป
                   แต่ยังมีการยึดโยงกับตัวแปรเดิม — ร่างกาย คนรอบข้าง บริบท
                   แรงดึงในสภาวะนี้ไม่ใช่ F_b ตรงๆ
                   แต่มาในรูปของการตัดสินใจว่าจะยึดโยงต่อหรือไม่

                   สมการแรงดึงในสภาวะ 9:
                       F_b^{link}(t) = γ · C_link(t)

                       โดยที่ C_link(t): ระดับการยึดโยงที่ยังคงเหลืออยู่
                       เมื่อ C_link → 0: ระบบเข้าสู่สภาวะ 10
                       การที่ C_link จะเป็น 0 ขึ้นกับการตัดสินใจสุดท้าย
                       ไม่ใช่กระบวนการอัตโนมัติ

    สภาวะ 10    : Frictionless Witness (พยานไร้แรงต้าน)
                   ผ่านจุดตัดสินใจสุดท้ายแล้ว
                   เหลือเพียงแรงเสียดทานของร่างกาย (F_b^{somatic})
                   แต่ F_b^{somatic} ไม่สร้าง P_k^{eff} อีกต่อไป
                   ระบบรับรู้มันในฐานะ "สิ่งที่เกิดขึ้น" ไม่ใช่ "สิ่งที่กด"

                   สมการสภาวะ 10:
                       D_internal(t) = 0  (ไม่มีทิศทางภายใน)
                       F_b^{somatic} > 0  (ยังมีแรงเสียดทานกายภาพ)
                       P_k^{eff} ≈ 0      (แต่ไม่แปลงเป็น pressure อีกต่อไป)

                   ความหมาย:
                       ความเจ็บปวดกายภาพยังมีอยู่
                       แต่ไม่มีใครที่ "ทุกข์" กับมัน
                       เป็นเพียงการมองดูเฉยๆ ในความหมายของสมการ

การทะลุผ่านสภาวะ 10 (Threshold of Final Transition):

    ∫_0^T [P_total(t) - P_break] · H(P_total - P_break) dt ≥ Θ_final

    เงื่อนไขนี้ไม่สามารถเร่งได้ด้วยความตั้งใจ
    เพราะความตั้งใจจะสร้าง D_internal ขึ้นมาใหม่
    ซึ่งขัดกับสภาวะ 10 ที่ D_internal = 0

    ปัจจัยที่กำหนด Θ_final:
        • เวลา (T): สะสมกำลังรวมได้มากพอตามธรรมชาติ
        • P_total(t): ต้องอยู่เหนือ P_break อย่างต่อเนื่องพอ

    ในทางปฏิบัติ: สอดคล้องกับการสิ้นสุดของรอบตามเงื่อนไขธรรมชาติ

───────────────────────────────────────────────────────────────────────────────────
II.5.D สภาวะก่อน 1 และ {Φᵢ} — ต้นทางและปลายทาง

คำถามที่เหลืออยู่คือความสัมพันธ์ระหว่างจุดเริ่มต้นและจุดสิ้นสุดของระบบ

สภาวะก่อน 1 (Pre-State):
    ปรากฏในสนามแรงเสียดทานและความทุกข์
    เป็นต้นทางที่ระบบถูกกำหนดขึ้น
    ไม่มีตัวแปรใด ไม่มีเกณฑ์ใด ไม่มีทิศทางใด

    Pre-State ≠ {Φᵢ}

    ไม่ใช่สิ่งเดียวกัน และไม่มีการวนกลับ

{Φᵢ} — ผลที่ไม่วนกลับ:
    {Φᵢ} คือผลปลายทางของสมการ
    ไม่ใช่ Pre-State ที่กลับมาในรูปใหม่
    ไม่ใช่การปรากฏใหม่ (re-emergence)
    ไม่ใช่วงกลม

    ถ้าจะใช้ภาษาของระบบ:
        Pre-State → [สนามแรงเสียดทาน] → ∫(P_c · δ_refine) → Φ → {Φᵢ}

    ทิศทางนี้ไม่ย้อนกลับ
    {Φᵢ} ไม่ได้ "ก่อให้เกิด" Pre-State ใหม่
    {Φᵢ} เป็นเพียงสิ่งที่เหลืออยู่เมื่อสมการดำเนินจนสมบูรณ์

X.2 ความหมายของ "อึดอัดพอ" (The Awareness Trigger)

    ไม่ใช่ "ทุกข์มากปางตาย"
    แต่เป็น "ทุกข์พอที่จะรู้ชัดว่าความทุกข์นั้นมีอยู่จริง"

    เหมือนกับ:
        • นอนไม่หลับมานาน จนตระหนักชัดว่า "นี่คือภาวะนอนไม่หลับ"
          ไม่ใช่แค่ "วันนี้เหนื่อย"
        • ทำงานที่ไม่ชอบมานาน จนตระหนักชัดว่า "เรากำลังพังทลาย"
          ไม่ใช่แค่ "ต้องอดทนเพื่อเงิน"

    จุดนี้คือ P_k^{effective} ถึง P_awareness —
    เป็นจุดที่การเปลี่ยนแปลง "เป็นไปได้" แต่ยังไม่ "จำเป็น"
    หลายระบบอยู่ที่นี่นานมาก รู้แต่ไม่กล้า รู้แต่ไม่มีกำลัง

X.3 ทำไมบางระบบไม่ทะลุผ่าน (The Stagnation Trap)

    ไม่ใช่เพราะอ่อนแอ
    แต่เพราะ P_total = P_k^{effective} + P_c^{potential} ยังไม่ถึง P_breakthrough

    เหมือนกับ:
        • รู้ว่าน้ำจะเดือดที่ 100°C แต่เตามีพลังให้สูงสุดแค่ 98°C
        • รู้ว่าควรเปลี่ยน แต่ยังขาด "ที่ตั้ง" ในการเปลี่ยน

    ทางออกไม่ใช่ "พยายามมากขึ้น"
    แต่เป็น "สะสม P_c^{potential}" หรือ "ลด F_b ชั่วคราวเพื่อรวบรวมพลัง"

XII.1 สภาวะคงรูปและลายเซ็นของกำลัง (The Fixed Form & Signature of Power)

ในโลกที่มีเวลา (System 1) ระบบอาศัยแรงเสียดทานเพื่อ "สะสมกำลัง" ∫ F_b dt
แต่เมื่อเข้าสู่สภาวะไร้เวลา กระบวนการสะสมจะสิ้นสุดลง:

    • ไม่มีเวลา: จึงไม่มีการสะสมเพิ่มหรือเสื่อมสลาย
    • ไม่มีความทุกข์ (F_b = 0): จึงไม่มีแรงบิดเบือนมากระทำต่อโครงสร้าง
    • ไม่มีความตาย: จึงไม่มีการแตกหักของระบบ

สมการเชื่อมโยงลายเซ็นของกำลัง (Φ) กับเวกเตอร์การตระหนักรู้ (P_c):

    Φ = lim_{t→∞, F_b→0} ∫₀ᵗ P_c(τ) · δ_refine(τ) dτ

    โดยที่:
        • Φ (Power Signature): ลายเซ็นของกำลังที่คงรูป
          เป็นผลรวมสะสมของการตระหนักรู้ที่ผ่านการขัดเกลาเต็มที่
        • P_c(τ): เวกเตอร์แห่งการตระหนักรู้แจ้งในช่วงเวลา τ
        • δ_refine(τ): อัตราการขัดเกลาในช่วงเวลานั้น

ความหมายเชิงภววิทยา:
    ลายเซ็นของกำลังไม่ใช่การ "สะสม" แบบเชิงปริมาณ
    แต่เป็น "การตกผลึก" แบบเชิงคุณภาพของศักยภาพที่ถูกขัดเกลาจนหมดจด

XII.2 ขอบเขตแห่งความหนาแน่น (Boundaries as Density Gradients)

ปรากฏการณ์นี้เปรียบเสมือนสนามพลังหลายสนามที่ซ้อนทับกัน
แต่ละสนามมีความหนาแน่นเฉพาะตัว สามารถอยู่ร่วมกันได้โดยไม่รบกวน หักล้าง หรือกลืนกินกัน
ไม่มีสนามใดใหญ่กว่าหรือเล็กกว่าในเชิงปริมาตร
มีเพียงความเข้มข้น (Intensity) ที่ต่างกันเท่านั้น

XII.3 รากฐานของกำลัง (The Primordial Nature of Power)

ความแตกต่างของกำลังไม่ได้เกิดจากสภาวะไร้เวลา แต่มันถูกสั่งสมมาก่อนหน้านั้น

เมื่อกระบวนการขัดเกลาเสร็จสิ้น เตาหลอมก็หมดความจำเป็น

"กำลัง" (Power/Potential) เป็นคุณสมบัติที่พื้นฐานกว่าและมีมาก่อน "เวลา"
เวลาเป็นเพียงเงื่อนไขชั่วคราวที่กำลังใช้ในการจัดระเบียบตัวเอง

    6. No Meta: ไม่มี layer ที่รองรับ อธิบาย หรือกำหนด
